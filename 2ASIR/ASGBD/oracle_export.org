#+TITLE: Guía de Migración con Oracle Data Pump (Expdp/Impdp)
#+AUTHOR: Héctor (Sysdba)
#+DATE: 2025-11-25
#+OPTIONS: toc:t num:t
#+STARTUP: showall

Contexto del Escenario

Héctor: Usuario SYSDBA. Administra permisos.

Pepe: Usuario origen. Tiene las tablas (=departamento=, =jefe=). Creará su propio directorio.

Iker: Usuario destino. Recibirá las tablas de Pepe en su propio esquema.

Fase 1: Permisos Iniciales (Héctor - SYSDBA)
Héctor debe conceder privilegios a Pepe para que pueda manipular directorios del sistema operativo y realizar la exportación.

#+BEGIN_SRC sql
-- Conectado como SYSDBA
-- 1. Permisos de conexión y almacenamiento para Pepe
GRANT CREATE SESSION TO pepe;
GRANT RESOURCE TO pepe; -- Incluye CREATE TABLE, etc.
ALTER USER pepe QUOTA UNLIMITED ON users;

-- 2. Permiso CRÍTICO para que Pepe cree el objeto DIRECTORY
GRANT CREATE ANY DIRECTORY TO pepe;

-- 3. Permisos de Data Pump (Opcional si solo es Schema export, pero recomendado)
GRANT EXP_FULL_DATABASE TO pepe;
#+END_SRC

Fase 2: Exportación de Datos (Pepe)
** 2.1 Creación del Directorio
Pepe define dónde se guardarán físicamente los archivos en el servidor.
/Nota: La ruta 'C:\backups' debe existir previamente en el sistema de archivos./

#+BEGIN_SRC sql
-- Conectado como PEPE
CREATE OR REPLACE DIRECTORY dir_pepe AS 'C:\backups';
-- Al ser el creador, Pepe tiene automáticamente permisos de lectura/escritura.
#+END_SRC

** 2.2 Creación del Parfile (exportar.par)
Pepe configura los parámetros de la exportación en un archivo de texto.

#+BEGIN_SRC conf :tangle exportar.par
DIRECTORY=dir_pepe
DUMPFILE=pepe_schema.dmp
LOGFILE=pepe_exp.log
SCHEMAS=PEPE

Opcional: Para excluir estadísticas si hay versiones incompatibles

EXCLUDE=STATISTICS

#+END_SRC

** 2.3 Ejecución del comando
Comando a ejecutar en la terminal del sistema operativo.

#+BEGIN_SRC sh
expdp pepe/password PARFILE=exportar.par
#+END_SRC

Fase 3: Preparación del Destino (Héctor - SYSDBA)
Antes de que Iker pueda importar, debe existir y tener acceso al archivo generado por Pepe.

#+BEGIN_SRC sql
-- Conectado como SYSDBA

-- 1. Crear al usuario Iker
CREATE USER iker IDENTIFIED BY password_iker;

-- 2. Permisos básicos para Iker
GRANT CREATE SESSION TO iker;
GRANT RESOURCE TO iker;
GRANT UNLIMITED TABLESPACE TO iker;

-- 3. Dar acceso a Iker al directorio creado por Pepe
-- Es necesario para que Iker pueda leer el archivo .dmp
GRANT READ, WRITE ON DIRECTORY dir_pepe TO iker;

-- 4. Permisos de Importación (Opcional pero recomendado)
GRANT IMP_FULL_DATABASE TO iker;
#+END_SRC

Fase 4: Importación de Datos (Iker)
Iker toma el archivo de Pepe y lo vuelca en su propio esquema usando =REMAP_SCHEMA=.

** 4.1 Creación del Parfile (importar_iker.par)
Configuración clave: remapeo de esquema y acción si existen tablas.

#+BEGIN_SRC conf :tangle importar_iker.par
DIRECTORY=dir_pepe
DUMPFILE=pepe_schema.dmp
LOGFILE=iker_imp.log

Mapeo: Origen(Pepe) -> Destino(Iker)

REMAP_SCHEMA=PEPE:IKER

Opcional: Si los tablespaces son diferentes (ej. USERS -> TBS_IKER)

REMAP_TABLESPACE=users:tbs_iker

TABLE_EXISTS_ACTION=REPLACE
#+END_SRC

** 4.2 Ejecución del comando
Comando a ejecutar en la terminal por Iker.

#+BEGIN_SRC sh
impdp iker/password_iker PARFILE=importar_iker.par
#+END_SRC

Verificación
Consultas SQL para validar que Iker tiene los datos.

#+BEGIN_SRC sql
-- Conectado como IKER
SELECT table_name FROM user_tables;
-- Debería mostrar: DEPARTAMENTO, JEFE

SELECT count() FROM departamento;
SELECT count() FROM jefe;
#+END_SRC
